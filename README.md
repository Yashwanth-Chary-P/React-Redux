# Redux Toolkit Todo App

A modern, responsive todo application built with React, Redux Toolkit, and Tailwind CSS. This project demonstrates state management using Redux Toolkit with a beautiful, glassmorphism-inspired UI.

## ✨ Features

- **Add and Remove Tasks**: Simple and intuitive task management
- **Modern UI**: Beautiful glassmorphism design with gradient backgrounds
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Smooth Animations**: Engaging user experience with CSS transitions
- **State Management**: Efficient state management using Redux Toolkit
- **Real-time Updates**: Instant UI updates when adding or removing tasks

## 🛠️ Technologies Used

- **React 18** - Modern React with hooks
- **Redux Toolkit** - Simplified Redux for state management
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Fast build tool and development server
- **React Icons** - Beautiful icon library

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <your-repository-url>
cd redux-toolkit
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 🎨 Design Features

- **Glassmorphism Effect**: Semi-transparent backgrounds with backdrop blur
- **Gradient Backgrounds**: Beautiful color transitions
- **Hover Animations**: Interactive elements with smooth transitions
- **Custom Scrollbars**: Styled scrollbars with gradient colors
- **Responsive Layout**: Adapts to different screen sizes

## 📱 Usage

1. **Adding Tasks**: Type your task in the input field and click "Add Task" or press Enter
2. **Removing Tasks**: Click the trash icon next to any task to delete it
3. **Viewing Tasks**: All your tasks are displayed in a clean, organized list
